Keybinds

  • A / L-Arrow == Move Left
  • D / R-Arrow == Move Right
  • W / Space / U-Arrow == Jump
  • P / ESC == Parcour Menu
  • - / ° == Back to spawn after Fall
  • 1 == 1st Block (Stone)
  • 2 == 2nd Block (Dirt)
  • 3 == 3rd Block (Grass)
  • 4 == 4th Block (Spike)

F1 for Cheats

How should it be played?

If you press P/ESC, you can try out my custom-made courses.
You'll receive a coin for completing them.
Try to complete as many courses as possible, take a screenshot, and send it to me to get on the leaderboard below.
