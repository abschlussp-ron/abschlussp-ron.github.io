Mein Abschluss-Projekt

Tasten

  • A / L-Pfeil == Links Bewegen
  • D / R-Pfeil == Rechts Bewegen
  • W / Space / O-Pfeil == Spring
  • P / ESC == Parcour Menu
  • - / ° == Back to spawn after Fall
  • 1 == 1st Block (Stone)
  • 2 == 2nd Block (Dirt)
  • 3 == 3rd Block (Grass)
  • 4 == 4th Block (Spike)

F1 for Cheats

Wie man spielt

Wenn du P / ESC drückst, kannst du meine selbst erstellten Parcours ausprobieren.
Dort (wenn du sie abschließt) erhältst du eine Münze.
Versuche, so viele Parcours wie möglich zu absolvieren, mach einen Screenshot und schick ihn mir, um in die untenstehende Bestenliste zu gelangen.
